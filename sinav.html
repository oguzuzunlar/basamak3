Hal Değişimi Süreçleri

Bu grafik, bir maddenin sıcaklığının zamanla nasıl değiştiğini ve hal değişim süreçlerini göstermektedir. Grafikte dört farklı bölge bulunmaktadır:

1. Buzun Isınması (0 ≤ x ≤ 2)

-10°C'den 0°C'ye kadar buzun ısınmasını gösterir.

2. Erime Süreci (2 < x ≤ 6)

0°C'de buzun suya dönüşümü gerçekleşir. Isı enerjisi, hal değişimi için kullanılır.

3. Suyun Isınması (6 < x ≤ 8)

0°C'den 100°C'ye kadar suyun ısınmasını gösterir.

4. Buharlaşma Süreci (8 < x ≤ 10)

100°C'de suyun buhara dönüşümü gerçekleşir. Isı enerjisi, hal değişimi için kullanılır.

Önemli Bilgi: Hal değişimleri sırasında sıcaklık sabit kalır çünkü verilen ısı enerjisi, moleküller arası bağları koparmak için kullanılır.
